# Krewko

Version stable : **Krewko 1.5.0 — build 4.5.0**. Les préversions restent disponibles séparément pour les essais.

L’application de gestion des organisations RP. Actes, stocks, armes, comptabilité, membres, permissions, renseignements, carte, planning et messagerie dans un espace partagé.

[Téléchargement Windows recommandé](https://krewko.fr/telecharger/windows) · [Site officiel](https://krewko.fr) · [Guides](https://krewko.fr/guides/utiliser) · [Support](https://krewko.fr/questions)

Ce dépôt distribue les fichiers Windows. Le projet source est maintenu séparément.

## Choisir son fichier

- **Krewko-Installation** est recommandé. Il installe le logiciel, ses raccourcis et le mécanisme de mise à jour.
- **Krewko-Portable** permet de lancer Krewko sans installation. Pour le mettre à jour, fermer l’application et remplacer manuellement le fichier.
- **SHA256SUMS.txt** fournit les empreintes des fichiers de chaque publication.
- Les scripts SQL servent à mettre une base existante à niveau selon ses prérequis. L’installation Windows ne les applique pas automatiquement.

Windows x64 et Internet sont nécessaires pour le fonctionnement partagé. Un gérant prépare la base Supabase du groupe et crée les comptes. Le moteur de carte et la lecture de captures sont livrés avec l’application. Les intégrations externes restent facultatives.

## Versions stables et versions de test

**Krewko 1.4.8 — build 4.4.8** désigne la même publication. Le numéro Krewko est destiné aux membres. Le build technique continue la progression des anciennes installations.

Les versions comportant beta sont des préversions. Elles doivent être testées avec une copie de base avant utilisation dans une organisation réelle. Le canal stable ignore ces préversions. Le guide de maintenance distingue la version de l’application et l’état des migrations de chaque groupe.

Une mise à jour ordinaire du nouveau client peut être reportée. Les anciennes versions peuvent encore imposer leur premier passage vers ce mécanisme. Les mises à jour indispensables conservent une exigence explicite de version minimale.

## Signature Windows

L’état de signature des fichiers est précisé dans les notes de chaque publication. Aucun certificat Authenticode utilisable n’était disponible pour préparer la version de consolidation. Les empreintes de téléchargement sont vérifiées par Krewko.

Pour un problème, indiquer la version, le build et le message affiché. Garder les mots de passe et codes de groupe privés.
